## Why

The first Passo navigation increment makes existing functions discoverable, but creating or importing a program still changes the calendar immediately and goals remain race-only. Complete the remaining experience in PIANO_RIPROGETTAZIONE_UX.md with durable reviewable proposals, truthful multi-program coordination, and coherent detail, recovery, nutrition and configuration journeys.

## What Changes

- Add a shared AI/file program journey with durable drafts, resumable generation, editable review, explicit destination and atomic activation separate from Garmin publication.
- Add independent versioned race and non-race goals, program associations and dated evidence-based evaluations that distinguish execution, progress and data quality.
- Evaluate proposed sessions against every active program and declared availability on the server, preserving existing and locked sessions and rejecting obsolete reviews or mandatory conflicts.
- Complete contextual training detail/editor/move/short-version journeys, Garmin status wording, activity analysis, recovery, nutrition diary/meal review, profile and first-use access.
- Add a local release switch, focused behavioral/browser verification, accessible states and a documented migration/rollback path; retain existing local edits and deep links.

## Capabilities

### New Capabilities
- `program-drafts`: Durable proposals and explicit, atomic, idempotent activation for AI generation and YAML imports.
- `program-coordination`: Server-verified availability, active-program context, stale-review protection and truthful compatibility limits.
- `training-goals`: Independent versioned goals, program links and evidence-qualified evaluations.
- `complete-training-experience`: Remaining detail, publication, activity, recovery, nutrition, configuration and accessibility flows.

### Modified Capabilities
- `plan-ownership`: Imports are reviewed before activation; replacement preserves protected sessions and historical identity rather than implicitly replacing every record.

## Impact

FastAPI schemas/routes, PostgreSQL migrations and transaction boundaries, generator proposal mode, goal evaluation services and frontend API/state contracts. Next.js program/goal pages and the remaining legacy flows adopt the shared workspace and navigation conventions. The app's AI provider/model configuration, sports algorithms and existing external integrations are retained. No deployment or external writes are part of implementation verification; real-user usability and live-service verification remain explicitly documented release activities.
